# Provisional Patent Application: Abstract

**Invention Title:** Methods and Systems for Real-Time Kinematic Anomaly Detection and Biomechanical Scaling in Remote Physical Rehabilitation

**Abstract:**

A computer-implemented system and method for real-time, zero-wearable kinematic sequence tracking and automated anomaly detection during remote physical rehabilitation. The system receives sequential monocular image frames from a client-side capture device and utilizes a localized processor to generate an initial matrix of spatial coordinate landmarks. To ensure uninterrupted spatial tracking when a patient's limbs are temporarily occluded from the camera's line of sight or fall below a visibility confidence threshold, the system employs a dynamic pre-inference landmark imputation module. This module establishes an anatomical baseline scalar derived from high-confidence, rigid skeletal anchor points (e.g., inter-shoulder bi-acromial distance). Utilizing this scalar, the system reconstructs the expected spatial coordinates of the occluded joints by projecting vectors proportional to the baseline scalar. The scaled, continuous coordinate matrix is asynchronously transmitted to a deep Bidirectional Long Short-Term Memory (BiLSTM) neural network. The neural network evaluates the temporal sequence to continuously execute concurrent state validation, while a parallel phase-state inversion algorithm analyzes the cross-correlation between the instantaneous vertical velocity vector of the user and localized ground-plane proximity to distinguish between intentional high-velocity exercise phases and true gravitational collapses, triggering automated therapeutic interventions upon detecting an anomaly.
