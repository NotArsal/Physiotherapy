## 4. Edge AI Inference Pipeline (Sequence Diagram)

This sequence details how raw camera data is transformed into a BiLSTM prediction without ever leaving the user's browser, preventing network latency and DOM blocking.

```mermaid

    autonumber
    actor User as Patient

    participant MediaPipe as MediaPipe (JS)

    User->>React: Performs physical movement
    React->>MediaPipe: Pass raw webcam frame
    MediaPipe-->>React: Return 33 3D Landmarks
    
    React->>Wasm: Pass landmarks to WebAssembly

    end
    Wasm-->>React: Return 99-feature imputed array
    
    React->>React: Push to 30-frame cyclic buffer
    
    React->>TFJS: Pass (30, 99) Tensor
    Note over TFJS: GPU Accelerated (WebGL)
    TFJS->>TFJS: BiLSTM-Attention Forward Pass
    TFJS->>TFJS: Strict tf.tidy() Memory Cleanup
    TFJS-->>React: Return Softmax Probabilities
    
    alt Probability > FNR Calibrated Threshold
        React-->>User: Visual/Audio: "Good Form!"
    else Probability < Threshold
        React-->>User: Visual/Audio: Corrective Form Warning
    end
```
